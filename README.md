# Tykarko

Landing page for Tykarko, the fully autonomous AI vehicle. Built with Next.js (App Router) and TypeScript.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

- `app/page.tsx` holds the page sections and copy.
- `components/Logo.tsx` holds the logo as SVG paths traced from the artwork in `public/brand/`.
